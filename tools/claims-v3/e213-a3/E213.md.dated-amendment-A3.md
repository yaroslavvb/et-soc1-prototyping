## A3-4. What it costs, and what it cannot show (REPORTED)

- **The drift's centre moves for the four gemmLnc points.** Pass 2 reverses pass 1, so a linear drift still cancels within each point's two runs;
  but the gemmLnc points' two runs are now symmetric about run 81.5, the other 37 points' about the middle tie (run 39). In the registered order
  every point was symmetric about run 43. A drift over the session therefore reads into the four gemmLnc points as the drift from run 39 to run
  81.5 (about half the session). The three ties (runs 1, 39, 77) read the drift up to the block (the scorer's day offset, REPORTED); no tie
  follows the block.
- **The card-time rule and the window's last start fall on the gemmLnc block first.** At the plan's 32.5 card-minutes against the 42-minute rule
  there are 9.5 card-minutes of margin; a slower day (the die gate waits) now cuts gemmLnc runs, where in the registered order it would have cut the
  end of pass 2.
- **A3 moves the stop; it does not prevent it.** If the board trips at k37's first run (run 79), runs 80-85 never start: k38's and k39's two runs
  and the second runs of k37 and k40 (k40's first run, run 78, is kept). The four gemmLnc points are 4 of arm B's 41 points and 4 of its 33
  cases; every other point keeps both runs.
- **The middle tie's thermal history changes**: in the registered order it ran right after the four gemmLnc runs; under A3 it sits between k41's
  two runs (runs 38 and 40).
  The ties are REPORTED only.
- A desk check of code cannot show a card's power. The numbers in A3-0 are verify-e213d's post hoc reading of arm A, not forecasts; the
  registered forecasts of k37-k40 stay as frozen and are scored as registered.
