## Protocol

1. **Desk, before this commit:** [`selftest_e124.py`](selftest_e124.py) `--full` (E109's committed data through E124's pipeline: the scorer with this frozen file reproduces E109's committed verdicts in every rule but R10; the set-aside rule picks the 3-pass reduction from E109's 2-kept one; N = 1.735 ± 0.164 W equals `posthoc.json`; the pipeline end to end on E109's raw passes); on the box: `check_e124.py` (19 files), the build, `V3_DRY=1` of the smoke and of pass 12410 (`build/e124/desk-*.log`).
2. This registration committed and pushed; then the claim, by rewriting the day's one card post in `#community-lab` (the lab's one-post-a-day rule of 1 Nov: a clause `using aifoundry1 card 1 for 1 h, until ~HH:MM PST` among the cards held).
3. [`session_e124.sh`](session_e124.sh), detached on aifoundry1 (`setsid nohup`, `E124_T0` = the claim's time): `check_e124.py`; `et-who`; the opening `ettelem config` under card 1's lock (`ET_DEVICES=1`, `timeout 10`); the smoke (12401: eight items, 2 s runs, no preheat) and E109's smoke gate, unchanged; if it passes, `queue_e124.sh`; the closing config read; `et-who`.
4. The release, by rewriting the day's post; the data collected to the Intel, reduced and scored with `pipeline_e124.sh`.

**Stops:** `build/e124/STOP`; another user's device process, a device node or this card's lock held by anyone else (block_e109.sh's `others_present`, exit 3; another user's idle login does not block, E78's departure D1 for `aifoundry1-c*`) stops the queue, with no retry; a failed pass stops it. **Nothing is set:** no governor, TDP, threshold or clock set, no reset, no PMIC command, no `--reset-ms`. The stock `ettelem` reads two PMIC voltage registers per `config` call and eleven per `sample` (reads, no write), as in every run since September: the owner's open question of 1 Nov, disclosed here, not settled. No new card session starts after 22:30 PST; every run ends by 23:30 PST.

**What a result changes.** If Z replicates, item 11's answer (per-time, not per-op work, not the lanes) holds as a registered result on a second card, and Y1 makes int8's no-issue excess a registered number. If Z contradicts, E109's labelled reading was a property of one card or one session. Either way the replicate the item asks for has run under a rule written before its data. Departures, if any, are dated amendments written before the data they touch.
