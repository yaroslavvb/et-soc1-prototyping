# E215, dated note 2 (post hoc): on both card days the never-run scan read copies of registration desks as runs; a scanner that skips them, for later kits

*Thu 19 Nov 2026 (week 47), PST. Written by the fix lane `fix-e215d` (Q224) after the data verifier `verify-e215d`. Its finding 3 and the
arm B card lane's own finding both asked for the scanner to be taught to skip PLANNED rows, registration desks and copied power records.
This note is **post hoc**: it was written after both arms' data commits (`8355db15`, `4f648f24`). It sits outside E215's pinned folder and
edits no committed file. E215's registered scanner (`tools/claims-v3/e215/desk/neverrun_e215.py`, sha256 `9e68b001...`) and card tool
(`desk/neverrun_card_e215.py`) stay as registered. No E215 label, rule, forecast or verdict changes. Every script here ran under
`/usr/bin/python3` 3.12.3, one thread, at the lab's `fd8b0ef4`.*

## 1. What the registered scan read on the card days

- **Arm B's step 6n** (13:41:38 PST): 26 of its 30 points read "ran after" (REPORTED and kept). All 44 hits are in two files of E217's
  registration desk, `configs-e217.json` and `scan-e217.json`, as the round's data lane for E217 holds them (arm B's README, departure 13).
- **The same report's arm A row**: 55 of 60 read otherwise. The causes are the same two files plus E217's copied power record,
  `card-record-e217.txt` (arm B's data, dated note 1). Arm A's own step 6n (12:05:06 PST) had read 60 of 60.
- **E213 arm B's day**: 126 hits, all in E214's registration and kit copies (that directory's dated note 1).

**The cause.** The scanner reads the round's lane folders whose names start `card-`, `data-`, `a1`, `a2` or `a3`. A data lane keeps a copy of
its experiment's registration tree (`reg-tree/`) and kit. A card lane keeps its own never-run outputs and its kit's stand-in doubles. These
files name configurations that were planned or looked for, not run. The registered scanners' docstrings say desk folders are not read, but
their lane roots let these copies in. No label came of it: on each judged day every such file was dated after the arm's freeze line, so each
reading was REPORTED and kept. The reports still misread.

## 2. The fix: `neverrun_skips_note2.py` (this folder)

The registered scanners run **unchanged**, loaded at their pins, except for their file reader, which the module wraps. A file the reader
skips is read as holding nothing. The rules:

| rule | what is skipped | why |
|---|---|---|
| **SKIP-DESK** | a path with a `reg-tree/` segment, or a `tools/claims-v3/` segment anywhere but directly under the lab's own top folder | a copy of a registration, kit or desk tree, or of a kit's stand-in doubles |
| **SKIP-NRDESK** | a never-run desk file of any experiment, wherever it sits: `scan-eNNN.json`, `neverrun-eNNN[-x].json/.txt`, `judge-eNNN[-x].json/.txt`, `configs-eNNN.json`, `labels-eNNN.json`, and the module's own `skips-eNNN-x.json` | an index of where configurations were looked for, never a run |
| **SKIP-RECORD** | `card-record-eNNN.txt` (E217's form) | a copy of the cards' committed power record; the runs it copies are read where they were committed |
| **SKIP-PLANNED** | in a JSON file that is read, every object whose `status` begins "PLANNED", or holds "not run" or "NOT RUN" | a row for a configuration that did not run; the rest of the file is read as before |

- **What stays the same.** The roots, the card classes, the subtraction, MM1-v3.1's measured points and the report's rules are unchanged.
  Every file the reader skips or thins is listed, with its rule and what its text held before and after, in `<out>/skips-e215-note2.json`.
- **What it still reads.** Lane copies of a proposal's arms and schedules outside a registration tree (a data lane's `work/src/`) stay in the
  scan, as E212's and E208's committed schedules do: the registered scanners read schedules as conservative evidence on purpose.
- **How a later kit takes it up.** It pins this file. Its card tool loads the file as "the scanner" (`neverrun_card_e215.py`'s form): the
  module re-exports the registered scanner's names, and its `e213_module()` returns the wrapped reader. The card tool calls
  `set_roots(lab, lanes)` before its rescan.

## 3. The tests

**The selftest** (`neverrun_skips_note2.py selftest <empty dir>`; printout `neverrun-skips-note2-selftest.txt`): **6 of 6 PASS.**

- **The stand-in tree** holds one file for each rule, one run record in a data folder, one in a card lane's run folder, a schedule among the
  lab's own committed E212 schedules (`tools/claims-v3/e212/proposal/src/sched/`), and a JSON index with one RAN row and two not-run rows.
- **The control,** the registered scanner unwrapped, reads every stand-in shape.
- **The wrapped scan** keeps the run records, the schedule and the RAN row, reads none of the others, and loses each one by its own rule. It
  keeps the S-kind run string in the data folder and drops the copied power record's.

**On the real folders** (`neverrun_skips_note2_test.py`; printout `neverrun-skips-note2-test.txt`, JSON `neverrun-skips-note2-test.json`).
T0, the registered scanner, and T1, the wrapper, ran back to back over the lab clone's committed folders and the round's lane folders, at
15:19:49-15:20:13 PST (84,214 files each). Both were reported with E215's registered candidates.

| | T0 (registered) | T1 (wrapped) |
|---|---|---|
| arm A: scored points never run | 5 of 60 (the reading arm B's day printed) | **60 of 60** |
| arm B: scored points never run | 4 of 30 (arm B's step 6n reading) | **30 of 30** |
| references read as run | r01, r02, r11, r12 | r01, r02, r11, r12 |

- **126 files skipped:** SKIP-DESK 70 (E212's, E214's and E217's registration copies in their data lanes; the E207, E210, E211 and E213 kits'
  stand-in doubles) and SKIP-NRDESK 56. SKIP-NRDESK includes 19 committed step-6n reports and judgements in E207's, E209's, E210's,
  E211's, E213's and E215's data folders.
- **SKIP-PLANNED and SKIP-RECORD skipped nothing here.** The PLANNED rows and the power record sat inside a registration copy, which
  SKIP-DESK covers first.
- **Every change from T0 to T1 is a skipped file's.** The scan has 2,647 (shape, card class) cells, of which 2,378 changed, and 65 (S kind,
  card class) cells. In each cell, T0's count of files holding the shape less T1's equals the skipped files of that class that held it. T1's
  masks are T0's less only masks named in skipped files, and the S-kind counts change only by the skipped files' run strings.
- **No run record was skipped:** no `run.json`, host output, telemetry, session log, queue or runner output.

The real-folder test reads lane folders that the lab does not keep, so it is a dated record. The selftest reproduces from the lab alone.
