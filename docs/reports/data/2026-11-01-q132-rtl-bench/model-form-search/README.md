# The search behind M4 and I3

Post hoc, and kept so it can be counted. `explore1.py` compared 11 float forms and `explore2.py` 7, 4 of them repeats, so **14 distinct float forms**, and **5 int8 forms**, on E78, E82, E86, E88, E90, E92, E94 and the bit ladders, before E95's data existed on main. Chosen: `core,bus,rest` for floats and `nets-bus,bus,clk` for int8. `obs.py` builds the observations. Run from this directory with numpy. Its E95 branch is not called.
