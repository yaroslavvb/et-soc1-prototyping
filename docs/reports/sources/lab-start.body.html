New user? Start now

30 September 2026 (PDT) · for new users of the AI Foundry ET-SoC-1 lab · part of the ET-SoC-1 measurement reports

The lab is three machines with four ET-SoC-1 cards, shared by several people and by jobs that run for hours. You do three things below; the prompt at the end tells your coding agent everything else.

Each card is an ET-SoC-1 on PCIe: 1,088 small RISC-V cores. The machines are x86_64 Ubuntu 24.04, reached over the lab's Tailscale network.

What you do

  1. Ask Roman for access. Roman runs the lab. Ask him, on the AI Foundry Discord's #community-lab, for an account on the lab machines, an invite to the lab's Tailscale network, and which machine and card to use.
  2. Join Tailscale and log in once. Accept the invite, install Tailscale, then run ssh <you>@aifoundryN and approve the link it prints in your browser.
  3. Give your agent the prompt. Paste it into your coding agent (Claude Code on your laptop works). The agent checks the machine, sets up a Claude that lives there in tmux with Remote Control, so you can drive it from claude.ai/code or the Claude app, and keeps to the lab's rules. It hands you the links only you can approve and asks before it touches a card.
